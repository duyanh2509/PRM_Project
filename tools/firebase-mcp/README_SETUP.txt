Firebase MCP was downloaded locally in this folder.

Installed package:
- @gannonh/firebase-mcp

To finish setup for Codex:
1. Download a Firebase service account key JSON from Firebase Console.
2. Save it as:
   D:\PRM393\PRM_Project\tools\firebase-mcp\serviceAccountKey.json
3. Copy the contents of CODEX_MCP_TEMPLATE.toml into:
   C:\Users\Admin\.codex\config.toml
4. Restart Codex.

Notes:
- google-services.json from the Android app is not enough for Firebase MCP.
- Firebase MCP needs an admin service account key.
